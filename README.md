## نظرة عامة على لغة C# ومنصة .NET

C# هي لغة تم إصدارها رسميًا في فبراير 2002، جنبًا إلى جنب مع منصة .NET 1.0 من Microsoft، والتي ترتبط بها ارتباطًا وثيقًا. تتطلب C# بيئة التشغيل هذه لتعمل، والتي توفر مجموعة واسعة جدًا من الفئات.

للوهلة الأولى، تعد منصة .NET بيئة تشغيل مشابهة لآلة Java الافتراضية، مع بعض الاختلافات الجديرة بالملاحظة:

**متعددة المنصات**: في حين أن Java كانت تعمل على أنظمة تشغيل مختلفة منذ بدايتها، كانت .NET مقتصرة في البداية على Windows. ومع ذلك، فإن مشروع **[Mono](http://www.mono-project.com)** يسمح الآن باستخدام .NET على أنظمة مثل Unix وLinux.


**متعدد اللغات**: تسمح منصة .NET بتشغيل البرامج المكتوبة بلغات مختلفة، بشرط أن ينتج مترجمها كود IL (اللغة الوسيطة). تتوفر جميع فئات .NET لهذه اللغات، مما يقلل من الاختلافات بينها؛ وبالتالي يصبح اختيار لغة .NET مسألة تفضيل أكثر منها مسألة أداء.





## تطور اللغة

في عام 2002 (C# 1.0)، كانت اللغة تشبه Java إلى حد كبير، مما سهّل الانتقال من بيئة إلى أخرى. ومنذ ذلك الحين، أصبحت السمات الخاصة بكل لغة أكثر تميزًا.

مع ظهور C# 3.0 وإطار عمل .NET 3.5، ظهرت العديد من الميزات الجديدة، وأهمها على الأرجح **LINQ** (Language INtegrated Query). تتيح LINQ الاستعلام عن المصفوفات أو القوائم أو قواعد البيانات أو ملفات XML بطريقة موحدة (مشابهة لـ SQL).

> 
> **ملاحظة**: هذا المستند ليس دورة تدريبية كاملة ولا يتناول LINQ. وهو مخصص لأولئك الذين لديهم بالفعل خبرة معينة في البرمجة ويرغبون في تعلم أساسيات C#. وهو مراجعة للمستند الأصلي الذي نُشر في عام 2002.
